## How to compile

### Option A — Overleaf (recommended, zero install)
1. Create a new blank Overleaf project.
2. Upload every file in this `paper/` folder (preserving the `tables/`
   and `figures/` subfolders).
3. Set the main document to `main.tex` and compile (pdfLaTeX or default).

### Option B — locally with Tectonic (what was used here)
```bash
brew install tectonic   # one-time, no sudo required
cd paper
tectonic main.tex       # produces main.pdf
```
This repository's `compiled_paper.pdf` / `main.pdf` were produced exactly
this way.

### Option C — a traditional TeX Live / MacTeX install
```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```
